# Carpeta de imágenes estáticas de ChapuZapp

Guarda aquí los recursos multimedia estáticos (logos, iconos, ilustraciones, avatares, etc.).
En Angular 19, todo lo que esté dentro de `/public` se sirve directamente en la raíz `/`.

Ejemplos de uso en componentes:
```html
<!-- Si guardas public/images/logo.svg -->
<img src="/images/logo.svg" alt="ChapuZapp Logo" />

<!-- Si guardas public/images/hero-illustration.png -->
<img src="/images/hero-illustration.png" alt="Ilustración" />
```
